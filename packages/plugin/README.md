# ปลั๊กอิน Arak สำหรับ Claude Code

ถามให้มาร์กข้อมูลส่วนบุคคล **ในเทิร์นที่ฟิลด์นั้นเพิ่งถูกเขียน** ไม่ใช่ในรายงาน CI สามสัปดาห์ถัดมา

## ฮุกสามตัว

| ฮุก | ทำอะไร |
|---|---|
| `SessionStart` | ยัดรายการวัตถุประสงค์ที่ประกาศไว้ในแคตตาล็อกเข้าบริบท พร้อมสถานะปัจจุบัน |
| `PostToolUse` (`Edit`\|`Write`) | ไฟล์ `.prisma` ถูกแก้แล้วมีฟิลด์ใหม่ที่ยังไม่ตัดสิน → บอกให้เติม annotation ทันที |
| `Stop` | เขียนแคตตาล็อกให้ตรงกับซอร์ส หนึ่งครั้งต่อเทิร์น |

## สิ่งที่ปลั๊กอินนี้ตั้งใจ **ไม่** ทำ

- **ไม่ขวางการจบงาน** — `PostToolUse` บล็อกไม่ได้อยู่แล้วตามการออกแบบของ Claude Code
  และเราไม่ใส่ `Stop` hook ที่ deny ด้วย เพราะเครื่องมือความปลอดภัยที่ขวางทางคือเครื่องมือที่ถูกปิดทิ้ง
- **ไม่เดา `purposes` ให้** — หมวดข้อมูลอ่านจากโค้ดได้ แต่วัตถุประสงค์กับฐานทางกฎหมาย
  เป็นการตัดสินใจทางธุรกิจ ฟิลด์ `email` ที่เก็บไว้ส่งใบเสร็จกับที่เก็บไว้ส่งโปรโมชัน
  หน้าตาในโค้ดเหมือนกันเป๊ะ แต่ฐานทางกฎหมายคนละข้อ ปลั๊กอินจึงสั่งให้ถามผู้ใช้เมื่อไม่มีอันไหนตรง
- **ไม่เตือนเรื่องเก่า** — ฟิลด์ที่มีอยู่ก่อนติดตั้งให้ยกเป็นหนี้เก่าด้วย `arak baseline`
  แล้วฮุกจะเงียบกับของเก่า เตือนเฉพาะสิ่งที่เขียนใหม่
- **ไม่ทำให้เซสชันพัง** — ทุกฮุกจับข้อผิดพลาดเองและจบด้วยรหัส 0 เสมอ
  ถ้ามีอะไรผิดจะบอกเป็นข้อความเตือน ไม่ใช่หยุดงานของคนใช้

## ติดตั้ง

ระหว่างที่ยังไม่ได้ปล่อยขึ้น marketplace ให้ชี้ตรงไปที่ไฟล์ใน `.claude/settings.json` ของโปรเจกต์

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "node",
            "args": ["${CLAUDE_PROJECT_DIR}/packages/plugin/hooks/on-edit.mjs"],
            "timeout": 15
          }
        ]
      }
    ]
  }
}
```

ดูชุดเต็มได้ที่ [`hooks/hooks.json`](hooks/hooks.json) และตัวอย่างที่ใช้จริงใน
[`.claude/settings.json`](../../.claude/settings.json) ของ repo นี้เอง

## หาไฟล์ตั้งค่าเจอได้เอง

ฮุกไล่หา `arak.config.yaml` ขึ้นไปจากไฟล์ที่เพิ่งถูกแก้ จนถึงขอบเขตของโฟลเดอร์ที่เปิด Claude Code อยู่
โครงแบบ monorepo ที่วางสคีมาไว้ที่ `apps/api/` จึงใช้ได้โดยไม่ต้องตั้งอะไรเพิ่ม
และถ้าโปรเจกต์ไหนไม่มีไฟล์ตั้งค่าเลย ฮุกจะเงียบสนิท
